# Skill: /projeto-sync-ta

Atualiza o TAP (ClickUp Doc) de um projeto com as informações mais recentes.

## Workflow
`workflows/escritorio-projetos/projeto-sync-ta.md`

## Uso
```
/projeto-sync-ta <codigo> <slug>
/projeto-sync-ta <codigo> <slug> <secao>
```

## Exemplos
```
/projeto-sync-ta 128 cnh-festival-agricultura
/projeto-sync-ta 128 cnh-festival-agricultura cronograma
/projeto-sync-ta 129 cnh-agrofuturo-escolas stakeholders
```

## Seções disponíveis
`cronograma` | `engajamento` | `comunicacao` | `financeiro` | `stakeholders`

Omitir a seção atualiza todas as seções vivas.
