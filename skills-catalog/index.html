Catálogo de Skills — NTICS Projetos

Skills de Claude Code que o Escritório de Projetos e o Marketing da NTICS usam no dia a dia — pra gerar painéis, orçamentos, carrosséis, sites, vídeos e muito mais. Copie o texto de qualquer uma e cole no seu próprio Claude Code, em .claude/skills/<nome>/SKILL.md.

Como usar uma skill dessas no seu Claude Code

  1. Clique em Copiar no card, ou abra Ver arquivo completo.
  2. No seu projeto, crie a pasta .claude/skills/<nome-da-skill>/.
  3. Cole o conteúdo copiado num arquivo SKILL.md dentro dela.
  4. Algumas skills têm IDs internos da NTICS (ClickUp, planilhas) trocados por placeholders como <ID_CLICKUP> — troque pelos IDs do seu próprio workspace antes de usar.
